Bookmarklet

This is the magic. The bookmarklet embeds your data and fills matching fields on any job site you're viewing in Safari.

  1. Tap Generate / refresh below.
  2. Tap Copy bookmarklet.
  3. In Safari, tap the share icon → Add Bookmark on this page. Save it (anywhere, you'll edit it).
  4. Tap the book icon → Edit → open the bookmark you just made → clear the address → paste → rename to "Fill App" → Done.
  5. Move it into Favorites so it shows in Safari's address bar.
  6. On any job application page, tap the address bar → tap Fill App. Boom.
